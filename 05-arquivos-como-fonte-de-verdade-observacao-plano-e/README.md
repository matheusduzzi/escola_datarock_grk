# Arquivos como fonte de verdade: observação, plano e execução

Arquivos do exercício dessa aula. São texto em Markdown: abrem em qualquer editor, e um leitor de Markdown mostra as tabelas formatadas. Você não precisa instalar nada nem ter acesso ao Grok Bot.

- `trechos-dos-arquivos.md`: cinco trechos, um de cada arquivo do case, sem o nome do arquivo.
- `cinco-frases.md`: cinco frases do case para classificar em observação, plano ou execução.
- `minhas-respostas.md`: o modelo com o quadro dos cinco arquivos e a tabela das cinco frases.

Salve uma cópia de `minhas-respostas.md` e responda na cópia. O quadro com a pergunta de cada arquivo e as três perguntas para classificar uma frase estão na página da aula.

O case foi anonimizado: não tente descobrir quem é a Criadora, os perfis ou as marcas. Os perfis com nome de exemplo, como @perfil_referencia_1, são marcadores do próprio case.

Para pedir ajuda, deixe um comentário na aula com o seu objetivo, o que você tentou, o que apareceu e onde parou, sem dados pessoais.
