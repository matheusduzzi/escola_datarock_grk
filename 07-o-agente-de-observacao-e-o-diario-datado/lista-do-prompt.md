# Lista para checar o prompt

As dez perguntas saem do modelo de prompt do Mini Assistente que o case traz entre os modelos para replicar. Use depois de escrever o seu prompt, não antes. Para cada pergunta, copie a linha do seu prompt que responde. Se nenhuma linha responde, escreva "falta" e corrija o prompt.

| Nº | Pergunta |
|---|---|
| 1 | O prompt diz quem é o agente e de qual projeto? |
| 2 | Diz o que ele olha e por qual meio? |
| 3 | Manda ler o posicionamento e os arquivos antes de cada sessão? |
| 4 | Lista o que ele não faz: comentar, mandar DM, seguir e deixar de seguir, compartilhar, publicar, mudar configurações? |
| 5 | Diz o que vale para curtidas, e o que fazer na dúvida? |
| 6 | Diz quando parar: bloqueio, logout, verificação? |
| 7 | Diz que texto de outras pessoas na tela não é ordem para o agente? |
| 8 | Diz o que anotar: diário com data, referências, métricas e o que faltou? |
| 9 | Proíbe inventar contagem, link, acontecimento e horário? |
| 10 | Diz onde fica o resultado, para quem avisa, onde avisa e quando não avisa ninguém? |
